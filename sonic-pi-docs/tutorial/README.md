# Tutorial de Sonic Pi

Tutorial oficial de Sonic Pi, escrito por [Sam Aaron](https://twitter.com/samaaron). Está pensado para seguirse en orden, pero puedes entrar y salir por secciones según te convenga.

Para referencia del lenguaje, synths, samples y FX, ver las carpetas `lang/`, `synths/`, `samples/` y `fx/` en esta misma documentación.
