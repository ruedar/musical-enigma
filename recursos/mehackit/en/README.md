# Sonic Pi workshop (English)

Contenido local del **Creative programming workshop with Sonic Pi** de [Mehackit](https://mehackit.org/), en versión texto (Markdown) para consulta y ejemplos.

- **Origen:** [sonic-pi.mehackit.org/exercises/en/](https://sonic-pi.mehackit.org/exercises/en/)
- **Licencia:** [Creative Commons Attribution-ShareAlike 4.0](http://creativecommons.org/licenses/by-sa/4.0/) (Mehackit). Basado en materiales de Raspberry Pi Foundation y Stuart Brett.

## Estructura

| Carpeta | Contenido |
|---------|-----------|
| `01-introduction/` | Introducción, melodía, repetición |
| `02-make-a-song/` | Hacer una canción: batería, bajo, lead, aleatoriedad |
| `03-tweak-the-sounds/` | Ajustar sonidos: opciones de synth, efectos |
| `04-generate-sounds/` | Generar sonidos: tick, variables, progresiones de acordes |
| `05-advanced-topics-1/` | Sample slicing, slicer, samples externos |
| `08-exporting-your-track/` | Exportar tu pista |
| `09-keys-chords-and-scales/` | Teclas, acordes y escalas |
| `10-cheatsheet/` | Chuleta de referencia |
| `11-templates/` | Plantillas (band, techno, hip hop, breakbeat, acid house, dubstep, etc.) |

Los archivos se generan con `scripts/scrape_mehackit_workshop.py` desde el repo.
